# Magasin Informatique Project
Projet réalisé dans le cadre du cours.

## Comment lancer le projet :
1. Installer les dépendances : `pip install flask mysql-connector-python`
2. Importer le fichier `database_backup.sql` dans MySQL Workbench.
3. Configurer les paramètres de connexion à la base de données dans `app.py`.
4. Lancer le projet : `python app.py`

## Analyse de sécurité :
Ce projet contient une démonstration d'une vulnérabilité HTTP (capture de données en clair via Wireshark) et propose une solution de sécurisation via HTTPS.
